# 入住预约 · 前端预览

原生微信小程序。当前包含入住预约页、页内核对弹层和已接入主流程的凭证预览页；预约页已实现前端日期、容量和必填校验，但没有后端、存储或真实提交。

## 打开

微信开发者工具导入本目录，读取 `project.config.json`。配置中的 `touristappid` 仅为占位值；当前版本的开发者工具需要先换成自己的有效 AppID，才能打开项目进行编译、模拟器检查和真机预览。

入口：`pages/reservation/index`。核对并确认信息后进入凭证预览页，但不会保存或提交预约。

## 手动验收

1. 以 375px 和 320px 宽度检查：顶部标题和猫咪不重叠，两张卡片没有横向溢出，页面能滚动到按钮和底部提示。
2. 点击日期，确认月历弹层可切换月份、点选日期并确认；北京时间当天和过去日期为禁用状态，只能选择明天或之后。关闭或点击遮罩取消时原日期不变。切换 1 / 2 晚，离店日期提示同步变化，并检查跨月、跨年和闰年。
3. 人数、房间数加减正常，最小为 1；3 人 1 间时显示容量错误且不能进入核对，调整为 3 人 2 间后错误清除。
4. 输入名字、微信号、备注，检查键盘弹出时输入框可见。
5. 名字或微信号为空时点击“核对预约信息”，确认弹层不会打开，缺失字段显示就地错误；填写完成后，核对弹层展示当前输入。长备注可滚动，点击“返回修改”、关闭按钮或遮罩返回表单，输入仍保留。
6. 点击“确认信息”后进入凭证预览页，确认入住、离店、晚数、人数、房间数和姓名与核对信息一致；页面明确显示“凭证预览”和“尚未提交”。
7. 在凭证预览页截图，或点击“保存预览凭证”检查保存反馈；返回预约页后，原表单输入仍然保留。
8. 将页面保持打开并跨过北京时间午夜，再次核对时已失效的入住日期被拦截，月历重新打开。
9. 关闭再打开小程序，表单恢复演示默认值；不会产生任何真实预约。
10. 真机检查顶部原生胶囊、底部安全区和乐米小奶泡体显示。

## 视觉处理

- 保留浅蓝底、深棕文字、左右图文、白色圆角卡片、蓝色选中态和主按钮。
- 使用原生导航栏，日期选择采用原生基础组件编写的月历弹层，不画虚假的返回按钮及右上角菜单。
- 所有文字为 WXML 文本或输入控件；背景、边框、按钮和日历图标均由 WXSS 实现，可直接修改。
- 猫咪为独立图片：`miniprogram/assets/cat.png`，由 imagegen 根据原概念图提取为透明背景独立素材，可能存在细节差异。橙色波浪线按用户偏好恢复为概念图局部裁切显示；概念图仅用于这个装饰，不用于文字或页面背景。
- 核对采用页内底部弹层；确认信息后进入凭证预览页。预览页不代表预约已保存或提交。

## 本轮验证记录

已通过 JSON 解析、JavaScript 语法、WXML 事件绑定检查，以及页面状态检查（日期资格、闰日、跨年、跨午夜、晚数限制、容量、必填、核对后进入预览和未提交语义）。文案变更后已重新生成字体子集。

微信开发者工具 CLI 服务端口已开启，并已使用有效 AppID 完成模拟器编译和运行验收。自动化检查覆盖未来日期选择、容量与必填拦截、核对弹层、确认后进入凭证预览、返回后输入保留和未提交语义；模拟器控制台未发现匹配 `error`、`exception` 或 `fail` 的日志。当前自动化接口不能切换设备宽度，因此 320px / 375px 专项视觉验收、真机相册保存和真机字体验证仍待人工完成。

## 页面字体

页面内容使用根目录的 `乐米小奶泡体.ttf`，由 `scripts/build-font.py` 提取当前 WXML / JS / JSON 中的字符及 ASCII 数字标点，生成 `miniprogram/styles/font.wxss`，在 `app.wxss` 全局引入。原始字体不修改，不进入小程序包。

修改文案后运行 `/Users/aaaa/miniconda3/bin/python scripts/build-font.py` 重新生成字体。脚本依赖 fontTools。用户输入中未收录的字符及原字体缺少的符号回退系统字体。微信原生导航栏仍使用系统字体。字体的真机显示尚待验收。
