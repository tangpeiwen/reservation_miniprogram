# 入住预约

原生微信小程序 + 微信云开发。当前包含入住预约页、页内核对弹层和正式凭证页；确认提交后由 `submitReservation` 云函数重新校验并写入 `reservations` 集合，保存成功后尝试通过 Resend 发送一次管理员邮件通知，随后展示服务端返回的预约编号、创建时间和凭证数据。数据库 `_id` 仅作内部主键，凭证展示服务端生成的 `reservationNumber`。

预约页支持转发给朋友和分享到朋友圈；凭证页仅允许把公共预约入口转发给朋友，不分享姓名、预约编号或其他凭证参数。

## 打开

微信开发者工具导入本目录，读取 `project.config.json`。项目已绑定 AppID 和云环境 `cloud1-d5g1dxxwj6b8f75fd`；云函数目录为 `cloudfunctions/`。

入口：`pages/reservation/index`。部署代码到其他账号或环境前，需要同步修改 `miniprogram/app.js` 中的环境 ID，并在目标环境创建 `reservations` 集合、禁止客户端直接读写、部署 `submitReservation` 云函数。邮件通知需要在云函数服务端配置 `RESEND_API_KEY`、`RESEND_FROM_EMAIL` 和 `RESERVATION_ADMIN_EMAIL`；这些值不写入小程序代码或版本库。

邮件通知使用 Resend API。预约保存记录先写入 `notificationStatus: "pending"`，函数只尝试发送一次，成功回写 `sent`，失败回写 `failed` 并保存 `lastNotificationError`；`notificationAttempts` 记录本次尝试次数。邮件发送失败不会撤销已保存的预约，用户仍会正常看到凭证。本轮不包含自动重试、定时补发或其他通知渠道。

开发者工具 Agent 配置在 `miniprogram/app.json` 的 `agent.skills`，项目内桥接 Skill 位于 `miniprogram/agent-skills/wechatide/`。这只服务于开发者工具的项目验证，不进入小程序运行时，也不改变云函数或数据库权限。若当前稳定版开发者工具返回 `agent compile mode is disabled`，说明该版本未开放 Agent 编译模式，使用标准预览即可。

## 手动验收

1. 以 375px 和 320px 宽度检查：顶部标题和猫咪不重叠，两张卡片没有横向溢出，页面能滚动到按钮和底部提示。
2. 点击日期，确认月历弹层可切换月份、点选日期并确认；北京时间当天和过去日期为禁用状态，只能选择明天或之后。关闭或点击遮罩取消时原日期不变。切换 1 / 2 晚，离店日期提示同步变化，并检查跨月、跨年和闰年。
3. 人数、房间数加减正常，最小为 1；3 人 1 间时显示容量错误且不能进入核对，调整为 3 人 2 间后错误清除。
4. 输入名字、微信号、备注，检查键盘弹出时输入框可见。
5. 名字或微信号为空时点击“核对预约信息”，确认弹层不会打开，缺失字段显示就地错误；填写完成后，核对弹层展示当前输入。长备注可滚动，点击“返回修改”、关闭按钮或遮罩返回表单，输入仍保留。
6. 点击“确认并提交”后，确认只有云函数保存成功才进入正式凭证页；凭证编号、提交时间、入住、离店、晚数、人数、房间数、姓名和优惠与数据库记录一致，并显示“预约申请已提交，尚未确认订房”。
7. 暂时断开网络或让云函数返回失败，确认仍留在预约表单、原输入不丢失并显示失败提示；恢复后重新填写一条测试预约。
8. 在正式凭证页截图，或点击“保存预约凭证”检查保存反馈；确认导出图片使用乐米字体、标题与预约编号不重叠，提交状态和时间完整位于白色卡片内。
9. 在预约页右上角菜单检查“转发给朋友”和“分享到朋友圈”，确认分享卡片进入预约入口；在凭证页确认只开放“转发给朋友”，且分享卡片不包含姓名、预约编号或凭证页参数。
10. 将页面保持打开并跨过北京时间午夜，再次核对时已失效的入住日期被拦截，月历重新打开。
11. 在云开发控制台确认小程序客户端不能直接读取、新增、修改或删除 `reservations`，但合法云函数提交可以写入。
12. 真机检查顶部原生胶囊、底部安全区和乐米小奶泡体显示。

- 保留浅蓝底、深棕文字、左右图文、白色圆角卡片、蓝色选中态和主按钮。

## 页面字体

页面内容使用根目录的 `乐米小奶泡体.ttf`，由 `scripts/build-font.py` 提取当前 WXML / JS / JSON 中的字符及 ASCII 数字标点，生成 `miniprogram/styles/font.wxss`，在 `app.wxss` 全局引入；脚本同时生成 `miniprogram/styles/font-subset.ttf`，保存预约凭证时将子集字体加载到 Canvas。原始字体不修改，不进入小程序包。

修改文案后运行 `/Users/aaaa/miniconda3/bin/python scripts/build-font.py` 重新生成字体。脚本依赖 fontTools。用户输入中未收录的字符及原字体缺少的符号回退系统字体。微信原生导航栏仍使用系统字体。字体的真机显示尚待验收。
